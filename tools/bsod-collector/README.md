# 蓝屏诊断一键采集

发给出故障的同事，双击 `双击开始采集.cmd`，自动提权，采集近 7 天的诊断数据并打包到桌面，再把压缩包发回分析。

## 采集内容

| 文件 | 内容 |
|---|---|
| 01_系统信息.csv | 厂商、型号、系统版本、BIOS 版本与日期、CPU、内存、上次启动时间 |
| 02_内存.csv | 内存条厂商、型号、容量、频率、插槽 |
| 03_设备.csv | 所有 PnP 设备及错误代码 |
| 04_设备驱动.csv | 驱动厂商、版本、日期、INF、是否签名 |
| 05_重点PCIe设备.csv | 按 VEN/DEV 过滤的可疑设备（ID 按案例修改） |
| 06_文件筛选驱动.txt | `fltmc filters`，用于排查安全软件驱动 |
| 07_磁盘状态.csv | 物理磁盘健康状态 |
| 08_蓝屏和硬件事件.csv | WHEA、Kernel-Power 41、BugCheck 1001、Kernel-PnP 219、volmgr 46、EventLog 6008 |
| 09_戴尔诊断事件.csv | Dell / SupportAssist / ePSA 相关事件 |
| 10_转储设置.txt | CrashControl 配置与分页文件 |
| Minidump/ | 最近 10 个小型转储 |
| 00_采集结果.txt | 每一项成功或失败及原因 |

## 设计要点

- **单项失败不影响整体**：每一项单独 `try/catch`，结果写进 `00_采集结果.txt`，分析时先看哪些项失败了
- **事件精确筛选**：按事件 ID 加提供程序名双重过滤，不导出整个系统日志
- **证据边界提示**：Dell 开机前硬件自检的结果不一定写入 Windows 日志，脚本会提醒另外记录 F12 诊断码
- **隐私提示**：转储和日志可能包含电脑名、账户、路径和内存内容，脚本提醒分享前检查

相关方法见 [工作站蓝屏/死机远程取证](../../docs/case-studies/workstation-crash-forensics.md)。
