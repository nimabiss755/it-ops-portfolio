# 新机一键部署（完整版）

新电脑入域之后，用一个脚本装完办公软件、调好电源策略，并收紧本地管理员权限。把脚本和安装包放在同一个目录，双击 `运行_新机安装.bat` 即可。实际使用中单台装机时间缩短约 1/3。

## 流程

1. 微信、企业微信、Everything、Chrome、终端安全客户端：**静默安装**
2. Office 365：通过 ODT（`setup.exe /configure`）离线部署
3. 电源策略：交流电不关屏、5 小时睡眠、高性能方案（方案不存在时自动复制）
4. 飞书：安装包不支持可靠静默安装，**放到最后**打开交互安装
5. **账户权限收口**：移除 `Domain Admins` 的本地管理员权限，移除并禁用出厂本地账户
6. 输出安装摘要表（成功 / 已安装 / 跳过 / 失败），日志写到 `%ProgramData%\CompanyProvisioning\`

## 设计要点

| 问题 | 做法 |
|---|---|
| 远程装机不能每步点 UAC | 启动器检测未提权时只提权一次；安装包用 `ProcessStartInfo` 且 `UseShellExecute = false` 直接继承管理员令牌，不再二次弹 UAC；`Unblock-File` 去掉下载标记，避免 SmartScreen 拦截 |
| 安装包版本经常换 | 按通配符匹配安装包，多个匹配时按优先级、文件版本、修改时间选最新一个，并记录警告 |
| 重复执行 | 先查卸载注册表（含 WOW6432Node 和 HKCU），已安装就跳过 |
| 缺包、单个失败 | 缺包自动跳过并记录；单个失败不中断后续步骤；退出码 0 / 1641 / 3010 视为成功（后两者标记需要重启） |
| 安装卡住 | 每个安装包有超时（默认 20 分钟），超时只记录失败、**不强杀进程**；每 30 秒提示仍在安装 |
| 控制台被鼠标点一下就"暂停" | 启动时关闭控制台快速编辑模式（QuickEdit） |
| 收口权限时把自己锁在外面 | 收口前检查：当前账号必须是**直接**加入本地 Administrators 的域用户，仅通过 Domain Admins 间接获得权限的不放行，否则跳过整个收口步骤 |
| 中英文系统组名不同 | 用 SID `S-1-5-32-544` 解析管理员组；移除后再按 SID 回查确认 |

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `-SourceDir` | 脚本所在目录 | 安装包目录 |
| `-InstallerTimeoutMinutes` | 20 | 单个安装包超时 |
| `-DomainAdminToRemove` | `CONTOSO\Domain Admins` | 要移出本地管理员组的域组（示例值，按实际修改） |
| `-LocalUserToDisable` | `olduser` | 要禁用的出厂本地账户（示例值，按实际修改） |

> 账户收口里的域前缀判断（`CONTOSO\*`）也需要改成实际的域 NetBIOS 名。

## 配套

先用 [快捷加域](../domain-join/) 入域并给使用人授权，再运行本脚本。
