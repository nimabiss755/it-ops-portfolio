# 快捷加域 + 域用户提权

新电脑加入 AD 域，并把使用人的域账号加入本地管理员组。双击 `运行_加域提权.bat` 运行。

## 为什么要分两次运行

入域后不重启，计算机和域控之间的安全通道还没建立好，立即把域账号加入本地管理员组会报错 **1789**（信任关系失败）。所以脚本把流程拆成两次：

1. **第一次**（还没入域）：设置 DNS → 预检域控 → 入域（可同时改名）→ 提示重启
2. **重启后用域管理员登录，第二次运行**：输入要授权的域用户 → 加入本地管理员组 → 按 SID 核验

不使用计划任务做"重启后自动执行"，脚本还会清理旧版本留下的计划任务。

## 设计要点

- **入域前预检**：把主用网卡（按默认路由选）DNS 指向域控 → 解析 `_ldap._tcp.dc._msdcs.<域名>` SRV 记录 → 测试域控 389 端口。任何一步失败就停止，不盲目执行 `Add-Computer`
- **输入校验**：域名格式、计算机名（1-15 位、不能全是数字、不能以连字符开头结尾）；已加入其他域的机器不会被自动迁移
- **账号写法兼容**：只输入用户名时自动补成 `user@域名`（UPN），避免猜错 NetBIOS 短域名
- **双通道加组**：先用 `Add-LocalGroupMember`，失败时改用 WinNT ADSI；加完后按 SID 回查，命令没报错但核验不过也算失败
- **执行前确认**：汇总域名、计算机名、DNS、要授权的用户，确认后才执行
- **分级退出码**：1 参数/取消，2 网络预检失败，3 入域失败，4 加组失败，方便批量执行时判断

## 参数

| 参数 | 说明 |
|---|---|
| `-DomainName` | 域名，不传则交互输入 |
| `-NewComputerName` | 新计算机名，回车保留原名 |
| `-AdminUsers` | 要授权的域用户，可多个 |
| `-DnsServer` | 域控 DNS，默认示例值 `10.0.0.10`，按实际修改 |

> 注意：DNS 会被**固定修改**为域控地址，脚本不会恢复原值。
