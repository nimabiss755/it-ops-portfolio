# 安全的临时文件清理

清理当前用户的临时文件和资源管理器缩略图缓存，释放 C 盘空间。

## 为什么叫"安全"

清理脚本最大的风险是删错地方。这个脚本在删除前先做两道路径校验：

1. `%TEMP%` 必须等于 `%LOCALAPPDATA%\Temp`，否则直接中止（防止环境变量被改成其他目录）
2. 缩略图缓存目录必须位于 `%LOCALAPPDATA%` 之下

## 清理范围

- `%TEMP%` 中 **7 天前**的文件和空目录（不动最近在用的临时文件）
- `thumbcache*.db`、`iconcache*.db`（会自动重建）

## 输出

执行后输出删除的文件数和释放空间（MB），删除失败的文件会跳过，不影响整体执行，只统计确实删掉的部分。
