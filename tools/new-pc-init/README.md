# 新机初始化脚本（早期版本）

新电脑到手后的第一步初始化，以管理员身份运行。

## 做了什么

1. 结束并卸载 OneDrive（自动判断 32/64 位系统，找对应的 `OneDriveSetup.exe`）
2. 关闭 Windows 防火墙（域/公用/专用）
3. 切换到高性能电源计划，硬盘永不关闭、计算机从不睡眠
4. 桌面显示「此电脑 / 用户文件 / 控制面板 / 网络」图标，并广播 `WM_SETTINGCHANGE` 刷新桌面
5. 下载并静默安装 Chrome、Everything

## 已知限制（后续完整版已改进）

- 下载失败没有重试和跳过逻辑，一个软件失败会影响后续步骤
- 静默参数统一传 `/silent /verysilent /s`，没有按安装包类型区分
- 关闭防火墙适用于由终端安全软件统一接管防护的环境，其他环境请按需删掉这一步
- 没有入域、本地管理员组、办公软件部署，这些在完整版里实现

完整版见 [tools/new-pc-deploy](../new-pc-deploy/)。
